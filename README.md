# DoIt — Vazifalar va Maqsadlar ilovasi

## APK qanday olinadi (GitHub Actions orqali)

1. Bu repository ni GitHub ga yuklang
2. "Actions" bo'limiga o'ting
3. "Build Android APK" workflow ni tanlang
4. "Run workflow" tugmasini bosing
5. 5-10 daqiqa kutib turing
6. Tugaganda "Artifacts" bo'limidan `doit-apk` faylni yuklab oling
7. ZIP ichidan `.apk` faylni chiqarib, Android qurilmaga o'rnating

## Lokal ishga tushirish (development)

```bash
pip install flet
python main.py
```
